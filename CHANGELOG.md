# Changelog

## 1.4.5 — 2026-10-14
**Settings restructure**
- Settings is now a main menu with five pages — *Theme mode*, *Animation + text*, *Catalogue*, *History & favorites* and *About* — each opening on its own with a back button. Only the open page is rendered, which fixes lag on phones.
- **Catalogue** page: a live preview of the home screen at the top that updates instantly as settings change.
- **Animation + text** page: shape & text settings, language, and a new **Page transitions (Beta)** setting (Off / Fade / Slide).
- **History & favorites** page: all history and favorites settings, Backup and Restore placeholders (*Coming soon*), and **Reset settings** (moved from About).


## 1.1.0-alpha — 2026-10-13
- **Updated Pop-up**: pop-up which notify user when new version of this APK release


## 1.1.0 — 2026-10-13
- Search moved to the top header; the home search bar now scrolls away with the page.
- **Favorites**: star any tool, view them on the Favorites page and as a row on the home screen.
- **History**: recently used tools and opened files, saved locally (localStorage + IndexedDB). Reopen items, remove one, or clear all.
- **Light Mode fixes** across every page, card, input, popup and navigation bar (active filter chips, toasts, "Download all as ZIP", extracted-text box). Popups now close when you navigate.
- Bottom navigation is now Home · PDF · Text · Favorites · Settings.

## 1.0.0 — 2026-10-12
- First release: 39 PDF tools and 202 text tools in one single-file app.
- Material You and iPhone-glass themes, dark mode, AMOLED black, accent colours.
- English and বাংলা interface.
- Android-style mobile layout with automatic device detection.
